# KeyLocker — Personal Password Vault

A modern, secure personal password vault web application with per-user vault isolation, automatic service favicon fetching, password generation, and 1-click clipboard copy.

## ✨ Features
- **User-Isolated Vault:** Architecture ready for per-user Google authentication so each user only sees their own passwords.
- **Auto Favicon Detection:** Automatically detects and displays high-res website favicons in real-time as you type, with full-bleed container styling.
- **Custom Icon Support:** Option to supply custom image URLs for private or internal tools.
- **Quick 1-Click Copy:** Fast username and password copying with instant visual feedback.
- **Strong Password Generator:** In-app randomized secure password generation.
- **Search & Filtering:** Live instant search across websites and usernames.

## 🛠️ Tech Stack
- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide React** (Modern Icons)

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/servicorex/password-locker.git

# Navigate to project directory
cd password-locker

# Install dependencies
npm install

# Start local development server
npm run dev
```
